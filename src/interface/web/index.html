Off: the search runs a fixed eleven-step pipeline — find companies, harvest, dedupe, filter, read each job, score, rank — the one drawn under Task DAG. On: a model designs those steps instead, deciding what runs and in what order. Measured just now, it spent $0.026 to produce the same eleven steps. Worth it only when your search is unusual enough to need a different shape.
